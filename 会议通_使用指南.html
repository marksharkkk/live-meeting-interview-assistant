会议通使用指南

第一次使用也能照着做：把会议声音变成实时字幕，显示中英对照，保存原始记录，并按需生成总结或回答建议。

这份指南可以直接双击打开，不需要联网阅读。按 Ctrl+P 可以打印或另存为 PDF。第一次使用请先完成“试录一次”，确认设备和语言正确后再用于正式会议。

先看懂它能做什么安装与启动第一次设置知识库 两分钟试录日常会议回答辅助 记录、总结与文件遇到问题

一、先看懂：会议通有四件事

先把声音变成文字，再对文字做翻译、总结或回答。这四件事可以同时存在，但不是同一个开关。

功能它做什么是否必须联网
实时字幕把麦克风、耳机或系统音频里的讲话识别成原文。语音识别在本机运行；第一次准备模型需要等待。
实时翻译在原文下面显示中文或英文译文。安装本地 OPUS-MT 后可优先本地翻译；否则使用主界面配置的在线模型。
会议记录与总结保存原始文字、可选原音频，并生成实时总结或结束后的完整总结。总结需要调用主界面配置的 AI 服务。
回答辅助根据最近字幕、选中的字幕或手动输入的问题生成可直接参考的回答。需要 AI 服务；生成期间不会停止监听。
知识库把你的简历、项目资料或会议材料提供给回答辅助作为参考。文件在本机处理；生成回答仍需要 AI 服务。
最简单的使用流程：打开提词器 → 选择音源和语言 → 点击“开始” → 看实时字幕 → 需要时切换“回答辅助”或开启“实时总结” → 点击“结束并保存”。

二、安装与启动

第一次安装

1
先安装两个小工具。uv负责按 uv.lock 创建项目自己的 Python .venv；Volta负责按 package.json 固定 Node.js、npm 版本。它们会帮助安装项目包，但本身不会自动安装；电脑已有就跳过。
winget install --id=astral-sh.uv -e
winget install Volta.Volta

安装后请关闭并重新打开 PowerShell 或命令提示符，检查：

uv --version
volta --version
2
双击项目目录里的 install.bat。它会执行 uv sync --locked 和 Volta 管理的 npm ci，把 Python 和 Node 包安装到项目环境。首次安装时间可能比较长。
3
安装完成后，双击 start.bat。桌面端会自动启动本地服务，不需要另外打开 Python 窗口。

项目目录通常是：

<项目目录>
如果窗口打不开：先关闭旧的会议通窗口；如果任务管理器里仍有旧的 meeting-assistant 或 Electron 进程，请结束旧进程后再双击 start.bat。第二次启动有可能只是唤醒旧版本，而不是加载刚更新的文件。

三、第一次设置

1. 配置 AI 服务

打开设置窗口的“AI 大模型配置”，填写 API Base URL、模型名称和 API Key，然后点击“保存 API 设置”，再点击“测试连接”。

服务API Base URL 示例模型示例
DeepSeekhttps://api.deepseek.com/v1deepseek-chat 或账户中实际可用的模型
OpenAI 兼容服务按服务商文档填写按服务商文档填写

API Key 是私密凭证。不要把它发给别人，也不要上传到 GitHub。项目会把它保存在本机的 backend\.env 中。

知识库：给回答辅助提供参考资料

知识库功能已经兼容当前统一工作台，但它只影响回答辅助：不会改变实时语音识别、字幕翻译，也不会自动加入会议总结。

  1. 打开主界面的设置窗口，在“知识库管理”区域选择 PDF、TXT 或 DOCX 文件。
  2. 点击“上传到知识库”，等待文件显示“已加载”。也可以把一段资料粘贴到“直接添加文本”中。
  3. 打开提词器的“回答辅助”，直接提问即可；当前回答辅助默认会查询知识库，再把相关内容交给 AI 参考。
按钮作用
刷新列表重新查看文件和已加载的文本块数量。
重新加载未加载文件文件还在但状态显示未加载时使用。
清理无效缓存文件被 Windows 资源管理器移走或删除后，清理旧记录。
清空知识库删除知识库中的上传文件和索引缓存；操作前请确认已经备份。

单个文件上限为 25 MB。知识库文件保存在项目的 backend\knowledge_base\uploads，索引缓存保存在同一目录；这些内容属于本机资料，不要上传到 GitHub。

3. 选择音频来源：你想听谁，就选择谁的声音所在设备

打开提词器后，展开“音源与语言”。最容易混淆的是音源选择：

你想识别的声音建议选择说明
线上会议对方的声音自动（系统音频回环），或选择当前耳机/扬声器的系统回环设备它读取电脑正在播放的声音。戴耳机时通常应选耳机对应的系统输出，不是耳机麦克风。
你自己说的话选择实际使用的麦克风可以是笔记本内置麦克风、耳机麦克风或外接麦克风。
只想识别对方，不想识别自己选择系统音频回环建议线上会议戴耳机，减少回声和重复识别。

如果设备列表里出现很多名称，不要只看“耳机”三个字：先确认会议软件把声音播放到哪一个设备，再选同一个输出。立体声混音不是首选；优先使用“系统音频回环”。

4. 选择识别语言和翻译目标

设置怎么选
识别语言中文、英文、中英混用或不确定时选“自动检测”；整场只有一种语言时可以手动选择。
字幕翻译“中英互译”适合一般场景；也可以固定“翻成中文”“翻成英文”，或选择“关闭翻译”。连续讲话时会先显示可替换的实时预览，完整句结束后才保存最终译文。
回答语言在“回答辅助”中选择“跟随问题”、中文或英文；它只影响 AI 回答，不改变字幕识别。
识别语言、翻译目标、回答语言是三件不同的事。例如：对方说英语 → 识别语言选自动 → 字幕翻译选翻成中文 → 回答语言选英文，就能看到英文原文和中文译文，同时生成英文回答建议。

四、先试录两分钟

  1. 打开提词器，展开“音源与语言”，确认音源和语言。
  2. 填写一个测试名称，确认“保存音频”是否勾选，然后点击“开始”。
  3. 让会议软件播放一段清楚的中文或英文讲话，观察左侧是否出现原文。
  4. 先看原文，再看下面的实时译文预览；它可能随着讲话继续被替换。完整一句结束后，最终译文才会保存到本场记录。
  5. 点击“暂停”，确认可以暂停；再点击“继续”，确认仍然是同一场记录。
  6. 点击“结束并保存”，然后在右侧场次列表中查看原始记录和中英对照。
试录通过标准：对方讲话时能出现原文；原文语言基本正确；翻译能出现；暂停/继续不丢记录；结束后能在历史场次中找到这次记录。全部通过后再用于正式会议。

五、日常会议怎么用

开始前

  1. 先打开腾讯会议、Teams、Zoom、飞书等会议软件，再打开会议通。
  2. 戴好耳机，确认对方声音确实从该耳机播放。
  3. 打开提词器，填写会议名称，选择是否保存音频。
  4. 点击“开始”，看到“监听中”后再开始正式讨论。

会议中

按钮/区域用途
暂停 / 继续暂停或恢复当前会话，不会新建场次。
实时总结勾选后大约每分钟根据截至当时的全部原始记录生成一次总结，默认关闭。
总结 / 回答辅助切换右侧工具。切换视图不会停止监听。
展开实时字幕隐藏 AI 侧栏，让字幕占满主要区域；再次点击可恢复。
清空字幕显示只清理当前屏幕，不删除本场原始记录、音频或答案。

结束后

点击“结束并保存”，等待最后一段字幕收齐。结束后可以生成完整总结，并查看：

  • 原始记录：未经字幕显示编辑的完整识别结果；
  • 中英对照：本场已完成的原文与译文；
  • 本场问答：本场生成过的 AI 问题和答案；
  • 完整总结：基于全部原始记录生成的总结。

六、回答辅助怎么用

回答辅助保留了原来的面试功能，但它现在属于同一场会议。生成答案时，会议仍然继续监听。

  1. 在右侧点击“回答辅助”。
  2. 如果字幕中有完整问题，可以点击“提取最近问题”；也可以在字幕中选中文字后点击“使用选中字幕”。
  3. 必要时直接在“本次问题”文本框中修改问题。
  4. 选择回答语言，点击“生成答案”。
  5. 如果答案不合适，点击“重新生成”。答案会保存到本场问答。
重要：AI 答案是参考建议，不是事实核验结果。面试时只使用自己的真实经历；正式会议中的敏感内容也应先确认是否允许使用 AI。

七、保存位置与 GitHub 安全

项目根目录是：

<项目目录>
内容保存位置
API Key 和本机配置backend\.env
会议元信息、原始记录、翻译、回答和总结backend\meetings\<会议ID>\
原始音频同一场次目录内的 audio-*.wav
Whisper 识别模型backend\whisper_models\
OPUS-MT 翻译模型backend\translation_models\
知识库原文和缓存backend\knowledge_base\
桌面端日志logs\desktop.log

发布到 GitHub 时，真实 API Key、会议录音、会议文字、知识库原文和模型文件都不要上传。项目中的 .gitignore 已经排除这些内容；公开仓库只保留 backend\.env.example。

操作作用

九、常见问题

现象先这样检查
提词器打不开或没有窗口先彻底结束旧的会议通/Electron 进程，再双击 start.bat；不要同时启动多个旧版本。若仍失败，查看 logs\desktop.log。
戴耳机但识别不到对方音源选择系统音频回环或耳机输出，不要选择耳机麦克风；先播放一段会议声音测试。
出现 Unanticipated host error暂停监听，换成“自动（系统音频回环）”或重新选择可用设备；关闭其他占用音频设备的软件后重试。
有声音但没有文字确认状态显示“监听中”，确认音量确实从所选设备播放，并选择自动检测或正确语言。
中英文混用识别不准识别语言选“自动检测”。如果整段语言固定，再手动选择中文或英文；重要人名、数字和结论要人工核对。
一直显示“翻译中”先看原文是否完整出现。翻译按完整句发送；检查 API 配置，或在字幕设置中暂时关闭翻译确认识别本身正常。
答案显示“已生成”但看不到打开“回答辅助”侧栏；如果当前是字幕全屏模式，点击“显示 AI 侧栏”。
没有完整总结先结束并保存本场记录，再检查 AI 模型配置和 API 余额，最后点击“生成完整总结”。
没有录音开始前勾选“保存音频”。已经结束的会议不能凭空补回开始前没有保存的声音。
每天只记住三件事：
1. 选对音源；2. 开始后确认原文出现；3. 结束时点击“结束并保存”。

这份指南对应会议通当前统一工作台版本。界面更新后，按钮文字可能略有变化，但“先选音源 → 试录 → 开始 → 结束并保存”的基本流程不变。
