# Bundled translation model attribution

The Windows ZIP bundles an English-to-Chinese OPUS-MT model converted to
CTranslate2 int8 format for local inference.

- Model authors and source: Helsinki-NLP, Tatoeba Translation Challenge
- Original model: `eng-zho/opus-2020-07-17.zip`
- Source page: https://github.com/Helsinki-NLP/Tatoeba-Challenge/tree/master/models/eng-zho
- Original download: https://object.pouta.csc.fi/Tatoeba-MT-models/eng-zho/opus-2020-07-17.zip
- Model license: Creative Commons Attribution 4.0 International (CC BY 4.0),
  as stated by the OPUS-MT training project:
  https://github.com/Helsinki-NLP/OPUS-MT-train#pre-trained-models
- License text: https://creativecommons.org/licenses/by/4.0/legalcode

The model's CC BY 4.0 terms remain separate from this application's personal
noncommercial license. Conversion to CTranslate2 int8 format changes the model
file format and quantization, not the attribution or the underlying license.
